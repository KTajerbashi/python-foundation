# راه‌اندازی پایتون در ویندوز

## ابزارهای لازم

### 1) Python
پیشنهاد این دوره: Python 3.14.x پایدار (نسخه نگه‌داری‌شده جدید از صفحه رسمی را انتخاب کن). نسخه‌های تازه‌تر ممکن است برای بعضی کتابخانه‌ها هنوز سازگاری کامل نداشته باشند؛ برای شروع، نسخه پایدار و پشتیبانی‌شده مناسب‌تر است.

دانلود رسمی: https://www.python.org/downloads/windows/

هنگام نصب:
- اگر از نصب‌کننده کلاسیک استفاده می‌کنی، گزینه افزودن Python به PATH را در صورت نمایش فعال کن.
- نصب را برای کاربر فعلی انجام بده، مگر اینکه دلیل مشخصی برای نصب سراسری داشته باشی.
- بعد از نصب، پنجره ترمینال را ببند و دوباره باز کن.

بررسی نصب در PowerShell:
```powershell
py --version
python --version
```
باید شماره نسخه Python نمایش داده شود. اگر `python` به Microsoft Store هدایت شد یا شناخته نشد، خروجی `py --version` را هم بررسی کن.

### 2) Visual Studio Code
دانلود رسمی: https://code.visualstudio.com/

نسخه Windows User Installer برای بیشتر کاربران مناسب است.

### 3) افزونه Python برای VS Code
در VS Code:
1. از نوار کناری وارد Extensions شو.
2. عبارت `Python` را جست‌وجو کن.
3. افزونه‌ای را نصب کن که ناشر آن Microsoft است.
4. در صورت پیشنهاد، Pylance و Python Debugger را نیز نصب کن.

راهنمای رسمی: https://code.visualstudio.com/docs/python/python-tutorial

## ابزارهای اختیاری
- Git: https://git-scm.com/downloads — برای ثبت تاریخچه تغییرات پروژه؛ در مراحل بعد استفاده می‌کنیم.
- GitHub account: https://github.com/ — برای نگهداری آنلاین کد؛ فعلاً اجباری نیست.
- Windows Terminal: https://aka.ms/terminal — محیط ترمینال راحت‌تر؛ PowerShell موجود هم کافی است.
- Jupyter: بعداً و فقط در صورت نیاز نصب می‌کنیم.
- کتابخانه‌های جانبی: فعلاً هیچ کتابخانه‌ای لازم نیست. `pip` و `venv` همراه نصب استاندارد Python در دسترس‌اند.

## ساخت پوشه تمرین
پیشنهاد:
```text
Documents/
└── Python-Learning/
    ├── lessons/
    ├── exercises/
    └── projects/
```
در VS Code از File > Open Folder پوشه `Python-Learning` را باز کن.

## اولین آزمایش
یک فایل به نام `hello.py` بساز و بنویس:
```python
print("Hello, Python!")
print("سلام! آماده یادگیری پایتون هستم.")
```
در ترمینال VS Code اجرا کن:
```powershell
py hello.py
```
باید هر دو پیام را ببینی.

## بررسی‌های تکمیلی
```powershell
py -m pip --version
py -m venv --help
```
این فرمان‌ها فقط وجود pip و ابزار محیط مجازی را بررسی می‌کنند؛ فعلاً چیزی نصب نمی‌کنند.

## نکته‌های مهم
- Python را از وب‌سایت رسمی دریافت کن.
- از نصب هم‌زمان چند توزیع پایتون یا Anaconda در شروع کار خودداری کن.
- کدها را در پوشه‌ای که دسترسی نوشتن داری نگه دار.
- برای هر پروژه جدی یک محیط مجازی جدا بسازیم.
- اگر هنگام نصب یا اجرا خطا دیدی، متن کامل خطا و خروجی فرمان‌ها را بفرست؛ رمز یا اطلاعات شخصی را ارسال نکن.
