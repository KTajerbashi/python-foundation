## آموزش و مثال‌ها

### پایتون چیست؟
Python یک زبان برنامه‌نویسی (Programming Language) است که با آن به کامپیوتر دستور می‌دهیم. از آن برای محاسبات، ساخت نرم‌افزار، خودکارسازی کارها، تحلیل داده و هوش مصنوعی استفاده می‌شود.

### دستور print()
تابع `print()` برای نمایش اطلاعات در خروجی استفاده می‌شود.

مثال:
```python
print("Hello World")
```
خروجی:
```text
Hello World
```

مثال چندخطی:
```python
print("سلام")
print("من در حال یادگیری پایتون هستم")
```
خروجی:
```text
سلام
من در حال یادگیری پایتون هستم
```

پایتون معمولاً دستورات را از بالا به پایین اجرا می‌کند.

### فایل پایتون
فایل‌های پایتون معمولاً پسوند `.py` دارند؛ مانند `hello.py` و `lesson1.py`.

### ساخت و اجرای اولین فایل
1. در VS Code پوشه `Python-Learning` را باز کنید.
2. فایل `hello.py` بسازید.
3. کد زیر را در آن قرار دهید و با `Ctrl + S` ذخیره کنید:
```python
print("Hello, Python!")
print("سلام! من برنامه نویسی را شروع کردم.")
print("This is my first program.")
```
4. در ترمینال VS Code اجرا کنید:
```powershell
py hello.py
```

خروجی مورد انتظار:
```text
Hello, Python!
سلام! من برنامه نویسی را شروع کردم.
This is my first program.
```

## معیار بررسی پاسخ و اشتباه‌های رایج
- فایل باید با پسوند `.py` ذخیره شده باشد.
- هر دستور `print()` باید پرانتز باز و بسته داشته باشد.
- متن باید داخل کوتیشن `" "` یا `' '` قرار بگیرد.
- نام فایل و مسیر اجرای فرمان باید درست باشد.
- در صورت خطا، متن کامل خطا و فرمان اجراشده برای بررسی ارسال شود.
- از کپی‌کردن پاسخ آماده خودداری شود؛ هدف، نوشتن و توضیح کد توسط هنرجو است.

## خطاها و نکته‌های مهم

- اگر `py` شناخته نشد، خروجی `py --version` و `python --version` را ارسال کنید.
