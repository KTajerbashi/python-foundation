# جلسه ۰۲ — متغیرها و انواع داده در پایتون

- شماره جلسه: ۲
- تاریخ: ۲۰۲۶-۱۱-۲۴
- عنوان: متغیرها، نام‌گذاری و انواع داده پایه
- مرحله مسیر: مرحله ۱ — مبانی
- وضعیت: تکمیل‌شده از نظر برگزاری و ثبت؛ تمرین‌های مستقل در انتظار بررسی

## هدف‌های جلسه

1. شناخت متغیر (Variable) و انتساب مقدار (Assignment)
2. رعایت قوانین نام‌گذاری متغیرها
3. شناخت انواع داده پایه `int`، `float`، `str` و `bool`
4. بررسی نوع داده با `type()`
5. استفاده از چند متغیر در یک برنامه ساده

## پیش‌نیاز / مرور جلسه قبل

هنرجو اعلام کرد جلسه اول به پایان رسیده است. موضوعات جلسه اول طبق نقشه راه: آشنایی با پایتون، محیط توسعه، اولین برنامه و اجرای فایل.

## آموزش و مثال‌ها

### ۱. متغیر و انتساب مقدار

متغیر نامی است که به یک مقدار اشاره می‌کند. از `=` برای انتساب مقدار استفاده می‌شود.

```python
age = 25
print(age)
```

خروجی:
```text
25
```

تغییر مقدار متغیر:

```python
age = 25
print(age)

age = 30
print(age)
```

خروجی:
```text
25
30
```

### ۲. قوانین نام‌گذاری

- نام متغیر نباید با عدد شروع شود.
- فاصله و خط تیره در نام متغیر مجاز نیست.
- استفاده از حروف، اعداد (پس از نویسه اول) و زیرخط `_` مجاز است.
- برای نام‌های چندبخشی، `snake_case` پیشنهاد شد.

نمونه:

```python
first_name = "Ali"
last_name = "Ahmadi"
user_age = 25
```

### ۳. انواع داده پایه

- `int`: عدد صحیح، مانند `10`
- `float`: عدد اعشاری، مانند `3.14`
- `str`: رشته متنی، مانند `"Hello"`
- `bool`: مقدار بولی؛ فقط `True` یا `False`

نمونه:

```python
name = "Kamran"
age = 30
height = 1.78
is_student = True

print(name)
print(age)
print(height)
print(is_student)
```

خروجی:
```text
Kamran
30
1.78
True
```

### ۴. بررسی نوع داده با `type()`

```python
name = "Kamran"
age = 30
height = 1.78
is_student = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))
```

خروجی:
```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

### ۵. نمونه ترکیبی

```python
first_name = "Kamran"
age = 30
city = "Mashhad"

print("Name:", first_name)
print("Age:", age)
print("City:", city)
```

خروجی:
```text
Name: Kamran
Age: 30
City: Mashhad
```

### ۶. تفاوت عدد و متن

```python
age = 25
age_text = "25"

print(type(age))
print(type(age_text))
```

نوع `age` برابر `int` و نوع `age_text` برابر `str` است.

## تمرین‌ها و وضعیت

- تمرین هدایت‌شده: تعریف متغیرهای `person_name`، `person_age` و `person_height`، چاپ مقدارها و نوع داده‌ها، سپس تغییر سن از ۲۸ به ۳۵ — وضعیت: در انتظار بررسی؛ نتیجه‌ای از هنرجو دریافت نشده است.
- تمرین مستقل ۱: تعریف متغیرهای نام، سن، شهر و وضعیت یادگیری برنامه‌نویسی و چاپ مقدار و نوع داده‌ها — وضعیت: در انتظار بررسی.
- تمرین مستقل ۲: تعریف `product_name`، `product_price`، `product_weight` و `is_available` و تشخیص نوع هرکدام — وضعیت: در انتظار بررسی.

## خطاها و نکته‌های مهم

- متن باید داخل کوتیشن قرار بگیرد؛ برای مثال `"Kamran"`.
- نام متغیر نمی‌تواند با عدد شروع شود.
- پایتون به بزرگی و کوچکی حروف حساس است؛ مقادیر بولی صحیح `True` و `False` هستند.
- `25` از نوع `int` است، اما `"25"` از نوع `str` است.
- `=` برای انتساب مقدار است، نه مقایسه ریاضی.

خطای مشخصی از اجرای هنرجو در این جلسه گزارش نشده است.

## تکلیف
