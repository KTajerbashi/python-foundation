# فهرست کامل دوره آموزش پایتون

**مبنای فهرست:** نقشه راه یادگیری پایتون — ۲۴ جلسه  
**هدف دوره:** یادگیری عملی پایتون از سطح مبتدی تا ساخت، آزمایش، مستندسازی و ارائه یک پروژه واقعی.

## مرحله ۰: آماده‌سازی (پیش از جلسه ۱)

- نصب و بررسی Python
- نصب و آماده‌سازی Visual Studio Code
- نصب افزونه Python
- ساخت پوشه پروژه و اجرای اولین برنامه
- خروجی مورد انتظار: اجرای موفق `print("Hello, Python!")`

## مرحله ۱: مبانی پایتون (جلسات ۱ تا ۴)

1. پایتون چیست؟ محیط توسعه، اولین برنامه و اجرای فایل
2. متغیرها، نام‌گذاری و انواع داده پایه
3. ورودی/خروجی، تبدیل نوع و قالب‌بندی رشته
4. عملگرهای ریاضی، مقایسه‌ای و منطقی + پروژه ماشین‌حساب

**خروجی مرحله:** ساخت یک ماشین‌حساب ساده

## مرحله ۲: منطق برنامه (جلسات ۵ تا ۸)

5. شرط‌ها: `if`, `elif`, `else`
6. حلقه `while` و کنترل تکرار
7. حلقه `for`, `range` و پیمایش رشته
8. مرور و پروژه بازی حدس عدد

**خروجی مرحله:** ساخت بازی حدس عدد

## مرحله ۳: ساختار داده (جلسات ۹ تا ۱۱)

9. لیست (List) و عملیات آن
10. تاپل (Tuple) و مجموعه (Set)
11. دیکشنری (Dictionary) و داده‌های کلید-مقدار

**خروجی مرحله:** ساخت یک دفترچه مخاطبان ساده

## مرحله ۴: توابع و ماژول‌ها (جلسات ۱۲ تا ۱۴)

12. تعریف و فراخوانی تابع (Function)
13. پارامترها، `return` و دامنه متغیر
14. ماژول‌ها، کتابخانه استاندارد و ساختار فایل پروژه

**خروجی مرحله:** ساخت یک برنامه چندبخشی و مرتب

## مرحله ۵: فایل و خطا (جلسات ۱۵ تا ۱۷)

15. خطاها و مدیریت استثنا با `try/except`
16. خواندن و نوشتن فایل متنی
17. کار با JSON و مسیرهای فایل

**خروجی مرحله:** ذخیره و بازیابی اطلاعات

## مرحله ۶: مهارت حرفه‌ای پایه (جلسات ۱۸ تا ۲۰)

18. محیط مجازی `venv` و نصب بسته با `pip`
19. دیباگ در VS Code و خواندن `traceback`
20. تست مقدماتی و Git

**خروجی مرحله:** ساخت پروژه‌ای همراه با تست و تاریخچه نسخه

## مرحله ۷: پروژه نهایی (جلسات ۲۱ تا ۲۴)

21. تعریف مسئله و طراحی پروژه نهایی
22. پیاده‌سازی نسخه اول پروژه
23. تکمیل، تست و رفع اشکال
24. مستندسازی، بازبینی و ارائه پروژه نهایی

**خروجی مرحله:** یک برنامه کامل و قابل اجرا

## روش عبور از مراحل

- تمرین‌ها را شخصاً اجرا کن و نتیجه را برای بررسی بفرست.
- برای عبور از هر مرحله، باید بتوانی مفاهیم را با زبان خودت توضیح بدهی.
- تمرین اصلی هر مرحله باید بدون کپی‌کردن پاسخ حل شود.
- در صورت نیاز، جلسه مرور یا جبرانی اضافه می‌شود؛ شماره جلسات اصلی تغییر نمی‌کند.

## پروژه نهایی پیشنهادی

تا زمان انتخاب پروژه نهایی، پیشنهاد اولیه دوره **برنامه مدیریت کارهای روزانه با ذخیره‌سازی JSON** است.
