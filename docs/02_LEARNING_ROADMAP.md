# نقشه راه یادگیری پایتون — 24 جلسه

## مقصد
در پایان مسیر بتوانی برنامه‌های خط فرمانی بنویسی، داده‌ها و فایل‌ها را مدیریت کنی، خطاها را کنترل کنی، از کتابخانه‌ها استفاده کنی، کد را تست و نسخه‌بندی کنی و یک پروژه قابل ارائه بسازی.

| مرحله | جلسات | موضوع‌ها | خروجی قابل سنجش |
|---|---:|---|---|
| 0. آماده‌سازی | پیش از جلسه 1 | نصب Python، VS Code، افزونه Python، ساخت پوشه پروژه و بررسی اجرا | اجرای موفق `print("Hello, Python!")` |
| 1. مبانی | 1–4 | آشنایی با برنامه، `print`, `input`, متغیرها، انواع داده، تبدیل نوع، عملگرها، رشته‌ها و f-string | ماشین‌حساب ساده |
| 2. منطق برنامه | 5–8 | شرط‌ها، مقایسه و منطق بولی، حلقه `while` و `for`، `range`, `break/continue` | بازی حدس عدد |
| 3. ساختار داده | 9–11 | list، tuple، set، dict، پیمایش و عملیات پرکاربرد | دفترچه مخاطبان ساده |
| 4. توابع و ماژول‌ها | 12–14 | تعریف تابع، پارامتر و مقدار بازگشتی، دامنه متغیر، ماژول‌ها و import | برنامه چندبخشی و مرتب |
| 5. فایل و خطا | 15–17 | مدیریت خطا، فایل‌های متنی، JSON، مسیرها و پوشه‌ها | ذخیره و بازیابی اطلاعات |
| 6. مهارت حرفه‌ای پایه | 18–20 | محیط مجازی، pip، نصب کتابخانه، دیباگ، تست مقدماتی، Git و GitHub | پروژه با تست و تاریخچه نسخه |
| 7. پروژه نهایی | 21–24 | تحلیل نیاز، طراحی، پیاده‌سازی، تست، مستندسازی و ارائه | یک برنامه کامل قابل اجرا |

## جزئیات جلسه‌ها
1. پایتون چیست؟ محیط توسعه، اولین برنامه و اجرای فایل
2. متغیرها، نام‌گذاری و انواع داده پایه
3. ورودی/خروجی، تبدیل نوع و قالب‌بندی رشته
4. عملگرهای ریاضی، مقایسه‌ای و منطقی + پروژه ماشین‌حساب
5. شرط‌ها: `if`, `elif`, `else`
6. حلقه `while` و کنترل تکرار
7. حلقه `for`, `range` و پیمایش رشته
8. مرور و پروژه بازی حدس عدد
9. لیست و عملیات آن
10. تاپل و مجموعه (set)
11. دیکشنری و داده‌های کلید-مقدار
12. تعریف و فراخوانی تابع
13. پارامترها، `return` و دامنه متغیر
14. ماژول‌ها، کتابخانه استاندارد و ساختار فایل پروژه
15. خطاها و مدیریت استثنا با `try/except`
16. خواندن و نوشتن فایل متنی
17. کار با JSON و مسیرهای فایل
18. محیط مجازی `venv` و نصب بسته با `pip`
19. دیباگ در VS Code و خواندن traceback
20. تست مقدماتی و Git
21. تعریف مسئله و طراحی پروژه نهایی
22. پیاده‌سازی نسخه اول پروژه
23. تکمیل، تست و رفع اشکال
24. مستندسازی، بازبینی و ارائه پروژه نهایی

## روش عبور از هر مرحله
- تمرین‌ها را خودت اجرا کن و نتیجه را ارسال کن.
- برای عبور از مرحله، بتوانی مفهوم را با زبان خودت توضیح بدهی و تمرین اصلی را بدون کپی‌کردن حل کنی.
- اگر لازم بود جلسه جبرانی یا مرور اضافه می‌شود؛ شماره جلسات اصلی در فایل‌ها حفظ می‌شود.
- پروژه نهایی با توجه به علاقه و هدف هنرجو انتخاب می‌شود؛ تا زمان انتخاب، پروژه پیشنهادی یک «مدیریت کارهای روزانه» با ذخیره JSON است.
